## ❓ FAQ

### Do I need to run it as Administrator?

No. This repository is an informational reference and does not contain software that needs to be launched.

### Does this repository include a Civilization VI hack executable?

No. It provides reference information about game modifications, debugging tools, and customization systems.

### Can Civilization VI be modified with community content?

Yes. Civilization VI supports community-created mods, including content distributed through the Steam Workshop.

### What development tools are available for Civilization VI?

The official development tools include ModBuddy, FireTuner, art and asset tools, and the Steam Workshop Uploader.

### Can modifications change units and game rules?

Yes. Civilization VI's modding system supports changes to game data, unit attributes, rules, maps, and other gameplay elements. Specific changes depend on the individual mod.
